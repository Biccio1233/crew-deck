# PRODUCT — Crew Deck

register: product

## Product purpose
A desktop crew board for people who run several AI coding agents at once (Claude Code, Codex, pi). It shows, at a glance, which session is working, which is finished, which is waiting for a human answer, in which folder, on which request, and at what cost. Later: request debriefing, project-brain health, a harbour for MCP/CLI services and a key vault.

## Users
- **Primary:** builders and consultants who keep 3–10 agent sessions open across projects during a workday, often non-full-time developers who direct agents rather than write code. The owner (Bix) runs agents for software and consulting work from a MacBook with terminals (Ghostty) on one side.
- **Secondary:** open-source users on macOS, Windows and Linux who discover it on GitHub.
- **Moment of use:** a glance, not a session. Two seconds to answer "does anyone need me?", then back to work. Occasionally a minute to read a request or check spend.

## Brand and tone
- Theme: the crew of a racing sailboat. You are the skipper; agents are crew roles (tactician, navigator, bowman, grinder, trimmer, helmsman); states are sailing language (calling the skipper, sailing, finished, in harbour).
- The metaphor lives in words, icons and one small animated boat. The interface itself is a serious instrument panel, not a themed toy: calm, precise, trustworthy, like the instruments on a race boat.
- Copy: short, direct, Italian first with English available.

## Anti-references
- Navy-and-ocean "nautical" clichés, rope textures, wood, anchors everywhere.
- Emoji as UI icons.
- SaaS dashboard tropes: hero metrics, identical card grids, gradients, glass.
- Cockpit/gamer neon.

## Strategic principles
1. Attention first: whoever is waiting for you is always on top and impossible to miss.
2. Glanceable: state readable from across the desk; detail on demand.
3. Quiet when nothing happens: no motion unless something is moving.
4. Honest: say when a state is an estimate.
5. Local and private by default.
